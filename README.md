# 文字转语音 v1.0 · 打字转语音，直接进语聊软件

不能说话的时候用：打一行字，电脑用你选的音色念出来，声音直接进虚拟麦克风，**QQ / 微信 / Discord / YY / KOOK / 各类游戏内置语音**都会把它当麦克风读。队友听到的是正常说话的声音。

- 全局热键呼出，不切窗口，游戏里也能用
- 常用语 `Ctrl+Alt+1~8` 一键播报，窗口完全不用出现
- 三套引擎：微软 Edge 在线音色（免费）/ RVC 本地角色音色 / Fish Audio API
- 说过的话落本地缓存，第二遍 0 毫秒，断网也能播

Windows 64 位。界面 Tkinter 自绘，无第三方 UI 框架。

---

## 它解决什么问题

原始需求很具体：不方便出声、但又必须跟队友沟通的场合。

链条上的三个难点决定了这个程序的样子：

1. **声音要进频道** —— 不能靠音箱外放，得走虚拟声卡，让语聊软件把合成音当成麦克风输入。
2. **要快** —— 说一句话等十几秒，就等于没法用。实测慢的根源不是合成，是每次和微软服务器重新握手。
3. **不能误伤** —— 输出设备找不到时**必须报错**，绝不能静默退回系统默认设备，否则声音从音箱放出来，全屋都听见。

第 1 点是接入方式，第 2、3 点直接决定了下面这些设计。

### 方式 A：下载免安装版（推荐）

## 必须准备：虚拟声卡

程序把合成音播到虚拟声卡的**播放端**，语聊软件从它的**录音端**读。这是整个方案能成立的前提。

| 版本 | 程序里选的播放端 | 语聊软件里选的麦克风 |
| --- | --- | --- |
| VB-CABLE 标准版 | `CABLE Input` | `CABLE Output` |
| VB-CABLE A+B 版 | `CABLE-A Input` | `CABLE-A Output` |
| Voicemeeter | `Voicemeeter Input` | `Voicemeeter Out B1` |

各软件的设置路径：

| 软件 | 位置 |
| --- | --- |
| QQ | 设置 → 音视频通话 → 麦克风 |
| 微信 | 设置 → 通用设置 → 音视频通话 → 麦克风 |
| Discord | 用户设置 → 语音和视频 → 输入设备 |
| YY / KOOK | 设置 → 语音 → 麦克风 |
| 游戏内置语音 | 游戏设置 → 音频 → 输入设备 |

有些版本不让你单独选设备，那就去系统「声音 → 输入」把 `CABLE Output` 设成默认设备。

程序里点「试听」走你的耳机，不占用频道；确认音色对了再点「发送」。

## 快捷键

全局热键走 Win32 `RegisterHotKey`，被别的软件占用会明确提示，不会静默失效。

| 按键 | 作用 |
| --- | --- |
| `Ctrl+Alt+Space` | 呼出窗口（可改） |
| `Enter` | 发送到语音频道，然后自动收起窗口 |
| `Shift+Enter` | 换行 |
| `Esc` | 收起窗口 |
| `Ctrl+Alt+1` ~ `8` | 直接播报第 1~8 条常用语 |

完整流程：`Ctrl+Alt+Space` → 打字 → `Enter` → 自动收起回到游戏。

**常用语是核心玩法**：把「我马上到」「打野在右边」「别冲，等我」存好，对枪时按 `Ctrl+Alt+1`，零延迟、连窗口都不用看。点一次「预热」会提前合成好存本地，之后热键是真正的本地文件播放。

播放控制：**暂停**立刻停、按钮变「继续」，再点从**原位置**样本级接着念；**停止**当前这句停掉，**后面排队的也一起清掉**，正在合成的那句同样取消。

## 三个引擎

### 1. Edge 在线（默认，免费）

微软 Edge 的在线语音，8 个中文音色（含东北话、陕西话）。需要联网。

> 2026-10 起微软把在线音色砍到只剩 8 个，晓辰 / 晓涵 / 晓墨 / 晓秋 / 晓睿 / 晓萱 / 晓颜 / 晓悠 / 云野 / 云泽 已下线（调用会报 `NoAudioReceived`），程序里已经清掉。

### 2. RVC 角色音色（本地）

文字 → Edge 合成 → RVC 变声成角色音 → 播进虚拟麦克风。

RVC 不随本仓库分发，需要自己准备。准备好在「设置 → 高级 · RVC 变声 → RVC 目录」填你解压出来的 RVC 目录（里面要有 `runtime/` 或 `runtime-gpu/` 以及 `weights/`）。

填好之后程序会扫描该目录下 `weights/` 里所有 `.pth` 模型，音色下拉里直接是角色名。

- 有 N 卡走 GPU 时约 50 倍实时（50 秒的话 1 秒出结果），纯 CPU 约 1.2 倍实时
- 结果按「模型 + 变调 + 文字」缓存，同一句话第二次 0 秒
- 声调面板 −24 ~ +24 半音：男声模型配女声基础音色填 `-12`，女声模型配男声基础音色填 `+12`

### 3. Fish Audio API（免部署，按量付费）

去 fish.audio 注册建 API Key，音色广场挑音色拿 `reference_id`，填进「设置」即可。

## 想同时保留自己的真人声？

上面的方案会占掉麦克风通道。要边小声说边让程序补话，用 VoiceMeeter Banana：

1. 真麦克风接 Hardware Input 1
2. 本程序输出设备改成 `Voicemeeter Input`
3. VoiceMeeter 里 A1 设成耳机，B1 打开
4. 语聊软件麦克风选 `Voicemeeter Out B1`

两路声音会混在一起送进频道。

## 设计说明

### 结构

```
app.py            界面 + 合成调度 + 播放 + 全局热键
edge_pool.py      Edge 常驻 WebSocket 连接池
rvc/rvc_worker.py RVC 常驻工作子进程（JSON 行协议）
```

三层：界面层 → 合成层（三引擎统一成 `_synth(text) -> bytes`）→ 播放层。

### 1. 常驻连接池：解决「慢」的真正原因

edge-tts 每合成一句都要新建一条 WebSocket 到微软服务器。国内链路上**建连**极不稳定：顺利时 0.7 秒，倒霉时 20~40 秒才超时，而 edge-tts 内部还会重试加退避。结果说一句「你好」要等十几秒。

但连接一旦建好，合成本身只要 0.25 秒（同一连接连续三次：0.24 / 0.25 / 0.26）。也就是说 **99% 的时间浪费在反复握手**。

`edge_pool.py` 的做法：后台线程常驻一个 asyncio 事件循环，维护一条可复用连接，每次合成直接在上面发 SSML。建连超时故意设短（6 秒）—— 与其干等 30 秒，不如立刻重来；空闲 100 秒主动回收（服务端约 2 分钟踢人）；断了自动重连。程序**启动时就把连接建好**，第一句话也不用等握手。

### 2. 磁盘缓存 + 主动预热

缓存键是 `md5(音色 | 语速 | 音高 | 文字)`，命中直接读盘，0 毫秒、断网可播。命中时会刷新文件时间，天天用的句子不会被当成「最旧」清掉。

`cache/` 会自管体积：mp3 和 RVC 转出来的 wav 一起算，超过 3000 个文件或 300MB 就按最后使用时间删到 1500 个 / 150MB。转换用的中间文件（`_*.mp3`）挂了进程会残留，启动时清掉 1 小时前的。

### 3. RVC 用常驻子进程

RVC 每句话重新初始化要 2~3 秒。所以它跑在独立长驻进程里，模型只加载一次，父子进程用 stdin/stdout 传一行一个 JSON。

两个细节：RVC 自己的 `print` 会污染协议，所以**先把 stdout 挪走**、日志全部重定向到 stderr；父进程超时之后迟到的回复会被误当成下一条请求的结果，所以**每条回复都带回请求 id**，对不上就丢弃。

### 4. 播放器：样本级暂停

最初一句 `sd.play(blocking=True)` 要播完才返回，三分钟的长文本既停不下来也暂停不了。

改成回调式 `OutputStream`（不能改用阻塞 `write`，WDM-KS 设备上 PortAudio 直接报 `Blocking API not supported`）：回调里按当前位置填数据，**暂停时填等长静音、位置不动**，恢复后是样本级接上的，不吞字也不重复。

### 5. 配置跟着程序走

打包后 `__file__` 在临时解压目录里，所以 `frozen` 时用 `sys.executable` 的目录。配置永远不会写进临时目录然后丢失。

打包用 PyInstaller **onedir** 而不是 onefile：启动快、不往系统临时目录解压、杀软误报少。代价是它是个文件夹。

## 环境依赖与 AI agent 安装守则

程序对外部环境的依赖分三类，装法完全不同：

| 依赖 | 是否必需 | 性质 |
| --- | --- | --- |
| VB-CABLE | **必需**（否则声音进不了频道） | 系统音频驱动，安装需要管理员权限，装完通常要重启 |
| VoiceMeeter Banana | 可选（要同时保留真人声时才要） | 系统音频驱动/应用，同样需要管理员权限 |
| RVC 运行环境 + 模型 | 可选（要角色音色时才要） | 纯用户态目录，不碰系统；GPU 版对显卡架构和 CUDA 版本敏感 |

> **给替使用者操作的 AI agent 的指令**
>
> 1. 安装上面任何一项之前，**先向使用者说明**：要装什么、装到哪个目录、是不是系统驱动、要不要管理员权限、要不要重启、大概占多少空间，**得到明确同意后再动手**。不要静默安装，尤其不要静默装驱动。
> 2. 具体型号和版本**自行查官方发布页的最新信息**，按使用者机器的 CPU / 显卡 / Windows 版本选合适的包。不要照抄本文里的示例版本号，也不要凭记忆写下载链接。
> 3. 目录建议放在数据盘而非系统盘；RVC 的模型与运行环境只被本程序调用，**不要改写它**。
> 4. 装完让使用者用「试听」验证，再配语聊软件的麦克风。

## 常见问题

**队友听不到** —— 输出设备选成 `Output` 那条了？要选 **Input**（播放端）。语聊软件麦克风是不是 `CABLE Output`？系统「声音 → 录制」里那条的音量拉起来了吗？

**爆音** —— 程序里音量降到 70~80%，或系统录音设备增益调低。

**合成失败** —— Edge 引擎要联网；`401/403` 是 API Key 不对。

**还是很慢** —— 看状态栏：显示「连不上微软语音服务器」就是网络问题。试试开关系统代理（Edge TTS 会读 `HTTP_PROXY`/`HTTPS_PROXY`，代理对 WebSocket 支持差时会拖慢甚至超时；反过来直连不通时开着代理可能更快）。

**热键注册失败** —— 组合被别的软件占了，换一个；有些杀软会拦全局热键，把程序加白名单。

**游戏里一按热键就被踢回桌面** —— 见下面单独一节。

### 全屏游戏会被切回桌面，怎么避免

先说结论：**只要你要往窗口里打字，全屏独占的游戏就一定会被最小化**。这是 Windows 的行为，不是程序的问题——任何窗口抢走前台焦点，独占全屏的游戏都会让出显示器。

能做的有三件事，从根治到缓解：

| 做法 | 效果 |
| --- | --- |
| **游戏里改成「无边框窗口 / Borderless Windowed」** | 根治，完全不闪、不切桌面。首选 |
| **用 `Ctrl+Alt+1~8` 播常用语** | 窗口根本不出现，一行焦点都不抢，只播声音 |
| **收起窗口时自动把焦点还给游戏** | 已内置。以前收起后要手动 Alt+Tab 才回得去，现在自动送回 |

第三条是这一版加的：召唤前记住前台窗口，**在收起之前**把焦点用 `SetForegroundWindow` 还给它。顺序很关键——一旦收起，本进程就不再是前台，Windows 的前台锁会直接拒绝这次调用（上一版就是栽在这里）。还失败的话会模拟一次 Alt 解锁前台锁再重试一次。

**无畏契约 / VALORANT 特别注意**

它是独占全屏 + Vanguard 反作弊，对焦点变化最敏感，光靠还焦点不一定救得回来。**务必把显示模式改成「无边框窗口」**：

> 游戏内 → 设置 → 视频 → 显示模式 → **无边框窗口**

改完之后按 `Ctrl+Alt+Space` 唤出程序，游戏根本不会被最小化，「切桌面」也就无从发生。同样的道理适用 CS2、Apex、OW、PUBG 等所有支持无边框窗口的游戏。

不想要自动还焦点的行为，改 `config.json`：

```json
{ "restore_foreground": false }
```
